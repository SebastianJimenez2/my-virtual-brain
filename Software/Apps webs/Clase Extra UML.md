# Proceso Unificado de Desarrollo
Los modelos son ciclos de vida.
El modelo de cascada no es una metodología, ni un proceso.
**Modelo**. Una forma de hacer algo y que se convierte en una plantilla que te da pasos a seguir.
>[!Note]
>Proceso descriptivo se usa cuando se tienen los requerimientos bien definidos, si el cliente posee incertidumbre, entonces, entra el agilismo.

**Caso de uso.** Función del sistema que genera valor al usuario.
**Pilares fundamentales de PU**
1. Dirigido por casos de uso. Partes de un caso de uso y no lo sueltas en todo el proceso.
2. Centrado en la arquitectura
3. Iterativo incremental
Para hacer el análisis de un CU se usa un diagrama de **robustez**.
# **Arquitectura MVC**
**Vista**. Cualquier interfaz de usuario que se tiene en un sistema.
**Modelo**. Modelo o entidad que participa en el **negocio**.
**Controlador**. Es el control de navegación, dice que cuando llegue una petición servirá como visagra entre el modelo y la vista.
El análisis es independiente de la plataforma.
En el diseño se empieza a pensar en la tecnología.

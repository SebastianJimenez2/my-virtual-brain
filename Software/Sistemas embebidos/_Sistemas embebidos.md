## Funciones principales de un SE
1. Preprocesamiento
2. Almacenamiento
3. Entrada / Salida
4. Interconexión (BUS)
>[!Note]
>Un sistema embebido debe tener un componente electrónico. 
## Características de un SE
1. Tienen capacidad limitada en cuanto a recursos.
2. Funcionalidad específica, es creado para un objetivo.

## Microcontrolador vs. Microprocesador

| Microcontrolador                           | Microprocesador            |
| ------------------------------------------ | -------------------------- |
| Sistemas embebidos => Propósito específico | Propósito general          |
| Bajo volumen de datos                      | Grandes volúmenes de datos |

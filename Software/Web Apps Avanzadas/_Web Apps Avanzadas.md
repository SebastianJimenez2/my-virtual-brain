## Bases de datos
### Relacionales
1. PostgreSQL
	1. Community => DGIP
	2. Enterprise
2. MS SQL Server
	1. **Enterprise** => Usado por Produbanco
	2. **Standard** => <mark style="background: #FFB8EBA6;">para medianas empresas o bancos</mark>, es la más popular => DGIP
